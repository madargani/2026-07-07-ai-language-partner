# Requirements: Language Partner Bot — v1.0 MVP

**Archived:** 2026-07-21
**Status:** ✅ SHIPPED

## v1 Requirements — Complete

### Setup & User Management

- [x] **SETUP-01**: User can run /setup to select native and target language — **VALIDATED** (Phase 1)
- [x] **SETUP-02**: User settings persist across bot restarts via PostgreSQL — **VALIDATED** (Phase 1)
- [x] **SETUP-03**: First-time /new triggers /setup if not configured — **VALIDATED** (Phase 1)
- [x] **SETUP-04**: Skill profile is inferred implicitly over time (starts at beginner) — **VALIDATED** (Phase 2)

### Conversation Sessions

- [x] **CONV-01**: User can start a session with /new [session_name] — **VALIDATED** (Phase 2)
- [x] **CONV-02**: Bot dispatches a target-language greeting matching skill profile — **VALIDATED** (Phase 2)
- [x] **CONV-03**: User replies via chat, bot responds with natural conversation — **VALIDATED** (Phase 2)
- [x] **CONV-04**: Correction budget enforces max 2 major errors corrected per message — **VALIDATED** (Phase 2)
- [x] **CONV-05**: Correction block is appended to the Discord embed (separate from response) — **VALIDATED** (Phase 2)
- [x] **CONV-06**: Session context is summarized after 20 turns to control costs — **VALIDATED** (Phase 2)
- [x] **CONV-07**: Only /summary or /end closes a session (no auto-expiry) — **VALIDATED** (Phase 2)
- [x] **CONV-08**: Session state persists to PostgreSQL and rehydrates on restart — **VALIDATED** (Phase 2)

### FSRS Spaced Repetition Bank

- [x] **FSRS-01**: Vocabulary items stored with FSRS fields (stability, difficulty, state, etc.) — **VALIDATED** (Phase 3)
- [x] **FSRS-02**: Grammar pattern items stored with same FSRS fields — **VALIDATED** (Phase 3)
- [x] **FSRS-03**: ts-fsrs algorithm updates scheduling on each review — **VALIDATED** (Phase 3)
- [x] **FSRS-04**: Cold start handled with population parameter seeding — **VALIDATED** (Phase 3)
- [x] **FSRS-05**: Review intervals capped at 14 days for first 3 months per item — **VALIDATED** (Phase 3)

### Background Extraction Pipeline

- [x] **EXTR-01**: User input is passed to low-tier LLM (GPT-4o-mini) concurrently with conversation — **VALIDATED** (Phase 4)
- [x] **EXTR-02**: Extraction output conforms to Zod schema (detectedItems, typosIgnored) — **VALIDATED** (Phase 4)
- [x] **EXTR-03**: Semantic filtering distinguishes cognitive mistakes from mechanical typos — **VALIDATED** (Phase 4)
- [x] **EXTR-04**: Code-switching detection auto-extracts native terms and injects as New items — **VALIDATED** (Phase 4)
- [x] **EXTR-05**: Extracted items update FSRS metrics in PostgreSQL — **VALIDATED** (Phase 4)
- [x] **EXTR-06**: Extraction pipeline runs via BullMQ/Redis for backpressure management — **VALIDATED** (Phase 4)

### Structured Review

- [x] **REVW-01**: User can run /review to fetch items where nextReview <= now — **VALIDATED** (Phase 4)
- [x] **REVW-02**: Review prompts include: use-in-sentence, fill-in-blank, and native-translation types — **VALIDATED** (Phase 4)
- [x] **REVW-03**: User response rated on FSRS scale (Again=0, Hard=1, Good=2, Easy=3) — **VALIDATED** (Phase 4)
- [x] **REVW-04**: Rating feeds into ts-fsrs scheduler and updates next review date — **VALIDATED** (Phase 4)
- [x] **REVW-05**: Review flow recurses until queue is clear or user exits via button — **VALIDATED** (Phase 4)

### Session Summary

- [x] **SUMM-01**: /summary terminates session and aggregates session data — **VALIDATED** (Phase 5)
- [x] **SUMM-02**: Embed displays top 3 strengths (items rated Easy during session) — **VALIDATED** (Phase 5)
- [x] **SUMM-03**: Embed displays expansion metrics (new items auto-extracted) — **VALIDATED** (Phase 5)
- [x] **SUMM-04**: Embed displays queue health (items due for review in next 24h) — **VALIDATED** (Phase 5)
- [x] **SUMM-05**: Summary persists to PostgreSQL for historical tracking — **VALIDATED** (Phase 5)

### Infrastructure & Deployment

- [x] **INFRA-01**: Application runs in Docker Compose (bot, PostgreSQL, Redis) — **VALIDATED** (Phase 1)
- [x] **INFRA-02**: Prisma ORM manages PostgreSQL schema and migrations — **VALIDATED** (Phase 1)
- [x] **INFRA-03**: LLM provider routing: high-tier for conversation, low-tier for extraction — **VALIDATED** (Phase 2)
- [x] **INFRA-04**: All slash commands use deferReply() to handle the 3-second Discord timeout — **VALIDATED** (Phase 1)
- [x] **INFRA-05**: Graceful shutdown saves in-memory session state to PostgreSQL — **VALIDATED** (Phase 1)
