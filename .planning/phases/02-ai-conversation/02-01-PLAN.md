    === PART F: Conversation Service (src/services/conversation.ts) ===
    Core service with these exports:
    - `activeSessions: Map<string, ActiveSession>` — in-memory cache of active sessions (keyed by thread ID)
    - `createSession(interaction, sessionName?: string): Promise<void>`:
      1. Verify user has configured language (prisma.user.findUnique)
      2. Defer reply immediately
      3. Create private thread via interaction.channel.threads.create() with ChannelType.PrivateThread, named by sessionName or date-fallback (D-05/D-06)
      4. Join thread + add user member
      5. Load system prompt from prompts/conversation/system.md
      6. Call GPT-4o-mini (model: "gpt-4o-mini") with system prompt + "Generate a target-language greeting for a language learner" to produce the opening message
      7. Send greeting to thread via thread.send()
      8. Persist Session to DB with userId, discordThreadId, status "active"
      9. Persist assistant greeting as Message (role: "assistant", content: greeting)
      10. Add to activeSessions cache
      11. Reply to interaction ephemerally with "Session started!"

    - `handleConversationMessage(thread, userId, content): Promise<void>`:
      1. Look up session from activeSessions by thread.id
      2. If not found or session.status !== "active", return silently
      3. Load recent messages from DB (last 10, ordered by createdAt asc)
      4. Build context array: system prompt, summary (if exists), recent messages (map role/content), user's new message
      5. Count total context tokens using tiktoken encoding_for_model("gpt-4o-mini"). If total exceeds ~82K (100K threshold - 16K max output - 1K buffer), trigger summarization flag
      6. Call openai.chat.completions.create with model "gpt-4o-mini", temperature 0.7, max_tokens 1024, messages array
      7. Parse response via parseCorrections() to extract corrections and response text
      8. Build embed: if corrections exist → orange embed with "📝 Corrections" field + divider line + "💬 Response" field (D-08). If no corrections → green embed with "✅ No errors found!" + divider + response (D-10)
      9. Send embed to thread
      10. Persist user message (role: "user") and assistant response (role: "assistant", hasCorrections: true/false) as Messages
      11. Update session messageCount/correctionCount
      12. If summarization flag triggered, call triggerSummarization (stub — real impl in Plan 02)

    - `parseCorrections(content: string): ParseCorrectionsResult`:
      1. Split by `##CORRECTIONS##` / `##SEPARATOR##` / `##RESPONSE##` delimiters
      2. Parse corrections section: split by newline, group into Correction objects (original/corrected/explanation)
      3. Cap at max 2 corrections (D-04)
      4. If no corrections found in the delimited block or corrections section says "No errors found", return corrections: null
      5. Return { corrections, response }

    - `buildConversationEmbed(corrections: string | null, response: string): EmbedBuilder`:
      1. Create EmbedBuilder
      2. If corrections: setColor(0xe67e22), addField("📝 Corrections", corrections), addField("─".repeat(20), "\\u200B")
      3. Else: setColor(0x2ecc71), addField("✅ No errors found!", "Great job! Keep going!"), addField("─".repeat(20), "\\u200B")
      4. AddField("💬 Response", response)
      5. SetTimestamp, return embed
